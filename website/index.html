Project Overview

Cubington is an interactive, standalone embedded gaming system developed on a custom-designed PCB utilizing the Texas Instruments MSPM0 microcontroller. The core game loop challenges the user’s spatial coordination within a strict time constraint. The game presents a 3D cube rendered on a display in a randomly generated target geometric orientation. The player controls a secondary cube on the screen simultaneously. The goal is to manipulate the second cube's horizontal and vertical axes to exactly mirror the geometry of the target cube. Players attempt to match as many distinct orientations as possible within a 60-second countdown window.

The hardware consists of a custom PCB, a Sparkfun analog switch joystick, and an Adafruit TFT LCD Screen. The joystick is the exclusive input, and the system uses advanced firmware and graphics optimizations to deliver a smooth, responsive experience on resource-constrained hardware. The project demonstrates efficient bit-packed memory management, smart partial screen updates, and clean analog filtering on a custom PCB to implement a responsive 3D puzzle game.
