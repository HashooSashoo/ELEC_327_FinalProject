Project Overview

Cubington is an interactive, standalone embedded gaming system developed on a custom-designed PCB utilizing the Texas Instruments MSPM0G3507 microcontroller. The core game loop challenges the player's spatial coordination within a strict time constraint: the game presents a 3D cube rendered on a TFT LCD display in a randomly generated target orientation. The player simultaneously controls a second cube, manipulating its horizontal and vertical axes via a Sparkfun analog joystick to exactly mirror the target. Players attempt to match as many distinct orientations as possible within a 60-second countdown window.

The hardware consists entirely of a custom PCB designed in KiCad, a Sparkfun analog switch joystick, and an Adafruit 1.8" TFT LCD screen. The project demonstrates efficient bit-packed memory management, smart partial screen updates, and clean analog signal conditioning on custom hardware to deliver a smooth, responsive 3D puzzle experience on severely resource-constrained hardware.
